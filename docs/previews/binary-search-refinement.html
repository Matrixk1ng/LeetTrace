Bounds and example code
Bounds are inclusive: low ≤ index ≤ high.
An empty interval has low > high.

low, high = 0, len(nums) - 1
while low <= high:
    mid = (low + high) // 2
    if nums[mid] == target:
        return mid
    if nums[mid] < target:
        low = mid + 1
    else:
        high = mid - 1
return -1
